# 🚀 Personal Portfolio - Fajar Tri Prasetyo

Portofolio digital modern dan interaktif milik **Fajar Tri Prasetyo** (Machine Learning & Software Engineer). Dibangun menggunakan Next.js 15, TypeScript, Tailwind CSS, GSAP animasi dinamis, dan Lenis smooth scroll.

---

## 🌟 Proyek Unggulan

Proyek-proyek yang ditampilkan dalam portofolio ini terhubung langsung dengan repository GitHub:
1. **[Bridge Capacity ML System](https://github.com/FajarPrasetyo/Machine-Learning---Prediksi-Kapasitas-Jembatan-)**: Sistem Machine Learning dua tahap (Gaussian Process Regression & Neural Network) dengan metodologi CRISP-DM dan antarmuka web interaktif Streamlit.
2. **[WGN Sport Center Platform](https://github.com/FajarPrasetyo/wgnsportcenter)**: Sistem reservasi lapangan olahraga dan manajemen operasional berbasis web (PHP & MySQL).
3. **[BlurryFace Portfolio v1](https://github.com/FajarPrasetyo/FajarPrasetyo.github.io)**: Portofolio personal generasi pertama dengan interactive particle network dan dark/light mode switcher.
4. **[Classroom Duty Manager](https://github.com/FajarPrasetyo/Aplikasi-Piket-Kebersihan-Kelas)**: Aplikasi tata kelola jadwal piket kelas dan tracking absensi tugas kebersihan.
5. **[Ambulance Emergency Dispatch](https://github.com/FajarPrasetyo/Ambulance-Bawa-Pasien)**: Simulasi sistem logistik dan respon darurat armada ambulans berbasis OOP Java.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router), React 19
- **Bahasa**: TypeScript, JavaScript
- **Styling**: Tailwind CSS, CSS Modules
- **Animasi & Interaktivitas**: GSAP (ScrollTrigger), Lenis Smooth Scroll, Lucide Icons
- **Deployment Target**: Vercel / GitHub Pages

---

## 🚀 Panduan Menjalankan Secara Lokal

1. **Install dependensi**:
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Jalankan development server**:
   ```bash
   npm run dev
   ```

3. **Buka di browser**:
   Kunjungi [http://localhost:3000](http://localhost:3000).

4. **Production Build**:
   ```bash
   npm run build
   npm run start
   ```
